## 读之前先知道的三个结论

1. **1.16.5 与 1.12.2 的渲染管线是两套东西** —— 姿态计算与绘制的生命周期不同，
   所以「护甲跟不跟动画走」「第一人称要不要跳过动画」这类问题在两代上答案完全不一样。
2. **1.12.2 没有 Brigadier**，命令层只能走 `ICommand` / `CommandTreeBase`。
3. **Aqua Acrobatics 是硬依赖且会重写玩家移动** —— 凡是"ParCool 自己也要做的"
   （改姿势、改尺寸、改视角），都必须先确认 Aqua 有没有已经做过。
